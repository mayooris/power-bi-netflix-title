# power-bi-netflix-title

📊 Project Overview

This project presents an interactive Netflix Data Analysis Dashboard created using Microsoft Power BI. The dashboard analyzes Netflix movies and TV shows to identify trends in content, genres, ratings, countries, release years, and other key attributes.

The project uses a Netflix dataset and transforms the raw data into meaningful visual insights through data cleaning, analysis, and visualization.

🎯 Objectives
1. Analyze the distribution of Movies and TV Shows on Netflix.
2. Identify the most common genres and content categories.
3. Analyze Netflix content by release year.
4. Examine content distribution across countries.
5. Analyze ratings and audience categories.
6. Identify trends in Netflix's content library.
7. Create an interactive dashboard for easy exploration of the data.
🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV
Data Visualization
📁 Dataset

The project uses a Netflix titles dataset containing information such as:

- Show ID
- Type
- Title
- Director
- Cast
- Country

- Release Year
- Rating
- Duration

🔄 Data Preparation

The dataset was processed using Power Query to:

- Remove unnecessary columns.
- Handle missing values.
- Correct data types.
- Clean and transform categorical data.
- Prepare the dataset for visualization.
- Create calculated measures using DAX.
